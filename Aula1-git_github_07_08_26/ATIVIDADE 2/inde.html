Atividades Práticas – Introdução à Linguagem C

Atividade 1 – Olá, Mundo!

Crie um programa que exiba: Olá, Mundo! Bem-vindo à programação em C.

Explicação: #include adiciona a biblioteca necessária para utilizar o printf. int main() cria a função principal, que é onde o programa começa. O primeiro printf mostra “Olá, Mundo!” na tela. O segundo printf mostra “Bem-vindo à programação em C.”. O \n significa quebra de linha, então a segunda mensagem aparece abaixo da primeira. O return 0 encerra o programa informando que ele funcionou corretamente.

Atividade 2 – Apresentação

Solicite o nome e a idade do usuário e exiba uma mensagem de apresentação.

Explicação: char nome[50] cria uma variável chamada nome para armazenar texto. O número 50 determina o espaço reservado para o nome. int idade cria uma variável chamada idade para armazenar um número inteiro. O primeiro printf pergunta o nome do usuário. O scanf recebe o nome digitado e coloca essa informação dentro da variável nome. %s indica que estamos trabalhando com texto. Depois, outro printf pergunta a idade. O segundo scanf recebe a idade. %d indica que o valor recebido é um número inteiro. O &idade indica o endereço da variável onde o número será armazenado. No último printf, %s é substituído pelo nome e %d é substituído pela idade. Por exemplo, se o usuário colocar Felipe e 16, o programa mostrará uma apresentação utilizando essas informações.

Atividade 3 – Soma

Leia dois números inteiros e exiba a soma.

Explicação: int numero1, numero2, soma cria três variáveis inteiras. numero1 guarda o primeiro número. numero2 guarda o segundo número. soma guarda o resultado. Os dois printf fazem as perguntas para o usuário. Os dois scanf recebem os números digitados. Depois acontece o cálculo da soma. O programa pega o valor de numero1, pega o valor de numero2 e adiciona os dois. O resultado é colocado dentro da variável soma. Por último, o printf mostra o resultado. Exemplo: se os números forem 10 e 5, a soma será 15.

Atividade 4 – Quatro operações

Leia dois números e mostre soma, subtração, multiplicação e divisão inteira.

Explicação: O programa começa incluindo a biblioteca stdio.h, que permite utilizar funções como printf e scanf. Depois, a função main indica o início da execução do programa. São criadas duas variáveis inteiras para armazenar os números digitados pelo usuário. O programa solicita os dois números e utiliza o scanf para armazená-los. Em seguida, realiza as operações de soma, subtração e multiplicação utilizando os operadores matemáticos correspondentes. Para realizar a divisão, o programa utiliza uma condição if para verificar se o segundo número é diferente de zero, evitando uma divisão inválida. Como as variáveis são do tipo inteiro, a divisão também é inteira, portanto a parte decimal é descartada. Caso o segundo número seja zero, o programa informa que não é possível realizar a divisão. No final, o return 0 indica que o programa foi encerrado corretamente.

Atividade 5 – Antecessor e sucessor

Leia um número inteiro e mostre seu antecessor e sucessor.

Explicação: O programa inclui a biblioteca stdio.h e inicia a função main. A variável numero é criada como um número inteiro. O printf pede um número ao usuário e o scanf armazena o valor na variável. Para encontrar o antecessor, o programa diminui 1 usando numero - 1. Para encontrar o sucessor, aumenta 1 usando numero + 1. Depois, os resultados são mostrados com printf.

Atividade 6 – Média

Leia duas notas (float) e calcule a média.

Explicação: O programa utiliza stdio.h para permitir os comandos de entrada e saída. As variáveis são do tipo float, porque as notas podem ter números decimais, como 7.5. nota1 guarda a primeira nota, nota2 guarda a segunda e media guarda o resultado. %f é utilizado no scanf para receber números decimais. A expressão (nota1 + nota2) / 2 soma as duas notas e divide o resultado por 2. Os parênteses fazem a soma acontecer antes da divisão. %.2f mostra o resultado com duas casas decimais.

Atividade 7 – Celsius para Fahrenheit

Leia uma temperatura em Celsius e converta usando F=(C*9/5)+32.

Explicação: O programa começa incluindo stdio.h e inicia a função main. São criadas duas variáveis float, pois temperaturas podem possuir casas decimais. celsius armazena a temperatura informada pelo usuário. fahrenheit armazena o resultado da conversão. O scanf recebe a temperatura em Celsius. Depois, o programa utiliza a fórmula da atividade: primeiro multiplica Celsius por 9, divide por 5 e adiciona 32. O resultado é armazenado em fahrenheit. Por fim, o printf mostra a temperatura convertida com duas casas decimais.

Atividade 8 – Área do retângulo

Leia base e altura e calcule a área.

Explicação: O programa utiliza a biblioteca stdio.h e inicia pela função main. São criadas três variáveis float: base, altura e area. O programa pede a base e a altura e utiliza scanf para receber os valores. Depois, utiliza o operador * para multiplicar a base pela altura. Essa multiplicação corresponde à fórmula da área do retângulo. O resultado é armazenado em area. O printf mostra a área com duas casas decimais.

Atividade 9 – Salário

Leia valor da hora e quantidade de horas trabalhadas. Calcule o salário.

Explicação: O programa começa incluindo stdio.h e inicia a função main. São criadas três variáveis float. valorHora armazena quanto a pessoa recebe por hora. horas armazena a quantidade de horas trabalhadas. salario armazena o resultado. O programa recebe o valor da hora e a quantidade de horas através do scanf. Depois, multiplica o valor da hora pela quantidade de horas. O resultado é armazenado em salario. O printf mostra o resultado utilizando R$ e duas casas decimais.

Atividade 10 – Calculadora

Leia dois números e mostre soma, subtração, multiplicação, divisão e resto da divisão.

Explicação: O programa inclui a biblioteca stdio.h e começa na função main. São criadas duas variáveis inteiras para armazenar os números. O usuário informa os dois valores através dos scanf. Depois, o programa realiza a soma, subtração e multiplicação. O if verifica se o segundo número é diferente de zero antes de realizar a divisão. O operador / realiza a divisão inteira. O operador % encontra o resto da divisão. Por exemplo, 10 dividido por 3 tem resto 1, então o resultado de 10 % 3 é 1. Se o segundo número for zero, o else mostra uma mensagem informando que não é possível dividir por zero.

Desafio Extra

Solicite nome, idade, nota 1 e nota 2. Exiba uma ficha do aluno contendo os dados e a média final.,

Explicação: O programa começa incluindo a biblioteca stdio.h, que permite utilizar printf e scanf. A função main indica onde o programa começa. A variável nome é criada como texto e possui espaço para armazenar até 50 caracteres. A variável idade é um número inteiro. As variáveis nota1, nota2 e media são do tipo float, permitindo armazenar números com casas decimais. O primeiro printf pede o nome e o scanf recebe essa informação. Depois, o programa pede a idade e armazena o valor na variável idade. Em seguida, recebe as duas notas. Depois que todas as informações foram recebidas, o programa calcula a média. As duas notas são somadas e o resultado é dividido por 2. O printf com ===== FICHA DO ALUNO ===== serve para criar um título e deixar a apresentação mais organizada. Depois, os outros printf mostram o nome, a idade, as duas notas e a média. %s mostra o texto do nome. %d mostra a idade, que é um número inteiro. %.2f mostra as notas e a média com duas casas decimais. O \n organiza as informações em linhas diferentes. Por fim, return 0 encerra o programa corretamente.
